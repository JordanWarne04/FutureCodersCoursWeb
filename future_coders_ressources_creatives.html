🛠️ Comment intégrer un effet ?

1. Essaie

Modifie les couleurs, les tailles ou l'animation dans l'outil.

2. Copie

Récupère le code HTML, CSS ou JavaScript proposé.

3. Colle

Place chaque partie dans le bon fichier de ton site.

4. Personnalise

Change le résultat pour qu'il corresponde à TON idée !
