2. Un bouton qui parle 💬

Dans index.html :

<button onclick="saluer()">
  Clique ici !
</button>

Dans script.js :

function saluer() {
  alert("Salut ! 👋");
}

Essaie le bouton dans la présentation.

Une fonction, c'est quoi ? 🔧

function saluer() {
  alert("Bonjour !");
}

Une fonction est une série d'instructions qu'on peut lancer quand on veut.

onclick="saluer()" = « au clic, lance la fonction »

🎯 Défi : change le message et le texte du bouton.

3. Changer le texte ✏️

<h1 id="titre">Mon site</h1>
<button onclick="changerTitre()">Surprise !</button>
function changerTitre() {
  document.getElementById("titre").textContent = "Bravo 🎉";
}

id="titre" permet à JavaScript de retrouver cet élément.

Un élément ou plusieurs ? 🔎

Un identifiant id : pour un élément précis.

document.getElementById("titre");

Une classe class : pour plusieurs éléments.

document.querySelectorAll(".carte");

Attention : querySelector(".carte") ne sélectionne que la première carte !

Changer tous les éléments d'une classe 🎨

Dans index.html :

<p class="carte">Carte 1</p>
<p class="carte">Carte 2</p>
<p class="carte">Carte 3</p>
<button onclick="colorier()">Colorier !</button>

Dans script.js :

function colorier() {
  document.querySelectorAll(".carte").forEach(function(element) {
    element.style.color = "tomato";
  });
}
🎯 Défi : fais changer la couleur de toutes les cartes de ton site.

Une classe, plusieurs possibilités 🧩

// Première carte seulement
const premiere = document.querySelector(".carte");

// Toutes les cartes
const cartes = document.querySelectorAll(".carte");

// Modifier chacune des cartes
cartes.forEach(function(carte) {
  carte.textContent = "Modifiée !";
});

Le point . signifie « classe » dans un sélecteur CSS, comme dans style.css.

Autre possibilité : document.getElementsByClassName("carte"), qui renvoie aussi une collection d'éléments.

8. C'est quoi un canvas ? 🖼️

Un <canvas> est une zone de dessin dans ta page HTML.

JavaScript peut y dessiner des rectangles, cercles, images… et les redessiner pour les animer.

<canvas id="jeu" width="600" height="350"></canvas>

9. Dessiner un personnage 🟦

const canvas = document.getElementById("jeu");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "royalblue";
ctx.fillRect(40, 80, 50, 50); // x, y, largeur, hauteur

Le point (0, 0) est en haut à gauche. x va vers la droite, y vers le bas.

🎯 Défi : change la couleur, la taille et la position du personnage.

10. Comment créer une animation ? 🎞️

On efface, on déplace, puis on redessine… encore et encore !

let x = 0;
function animer() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = "royalblue";
  ctx.fillRect(x, 100, 50, 50);
  x += 2;
  requestAnimationFrame(animer);
}
animer();

requestAnimationFrame() demande au navigateur de dessiner la prochaine image.

Regarde, il bouge ! 🏃

Le personnage est redessiné à une position différente à chaque image.

11. Bouger avec les flèches ⌨️

let x = 100;
let y = 100;

document.addEventListener("keydown", function(event) {
  if (event.key === "ArrowRight") x += 10;
  if (event.key === "ArrowLeft")  x -= 10;
  if (event.key === "ArrowUp")    y -= 10;
  if (event.key === "ArrowDown")  y += 10;
});

Dans la fonction d'animation, dessine ton personnage avec :

ctx.fillRect(x, y, 50, 50);

Essaie les flèches ! 🎮

Clique sur la zone de jeu puis utilise ← ↑ ↓ → (clique ailleurs pour reprendre la navigation)

12. Remplacer le carré par une image 🧑‍🚀

const personnage = new Image();
personnage.src = "personnage.png";

function animer() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  if (personnage.complete && personnage.naturalWidth > 0) {
    ctx.drawImage(personnage, x, y, 60, 60);
  }
  requestAnimationFrame(animer);
}
animer();

Place personnage.png dans le même dossier. Garde aussi le code des flèches de la slide précédente.
